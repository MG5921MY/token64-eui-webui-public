# IPv6 Token WebUI - 项目说明

🌐 基于 Rust 的 IPv6 Token 配置管理 Web 界面

## ⚠️ 重要说明

**本程序仅支持 Linux 系统运行**

- ✅ **支持**: Debian 12, Ubuntu 20.04+, CentOS 8+, Arch Linux 等
- ❌ **不支持**: Windows, macOS
- 📋 **依赖**: NetworkManager, iproute2, sysctl

**原因**: 程序依赖 Linux 特定的网络管理工具（`nmcli`, `ip`, `sysctl`）

## 🎯 功能特性

- ✅ **单一可执行文件** - 无需外部依赖，开箱即用
- ✅ **跨架构支持** - 支持 x86_64, ARM64, ARM32
- ✅ **多层安全防护** - 输入验证、命令注入防护
- ✅ **低资源占用** - 内存占用 < 10MB
- ✅ **现代化界面** - 响应式设计，支持深色/浅色主题
- ✅ **实时日志** - 操作日志实时显示

## 🚀 快速开始

### 方式 1：直接运行（开发测试）

```bash
# 进入项目目录
cd code

# 运行程序
cargo run

# 访问 http://localhost:5000
```

### 方式 2：编译发布版本（推荐）

```bash
cd code
cargo build --release

# 运行
./target/release/ipv6-token-webui

# 访问 http://localhost:5000
```

### 方式 3：Docker 部署

```bash
cd code
docker compose up -d

# 访问 http://localhost:5000
```

|------|------|
| 二进制大小 | ~4MB |
| 内存占用 | <10MB |
| 启动时间 | <1秒 |
| 响应时间 | <50ms |

## 🔒 安全特性

1. **输入验证** - 正则表达式严格验证所有输入
2. **命令注入防护** - 使用参数数组而非 shell 字符串
3. **超时控制** - 60 秒超时自动终止
4. **日志审计** - 记录所有操作

## 📝 API 端点

- `GET /api/system/info` - 获取系统信息
- `POST /api/ipv6/enable-token` - 启用 Token
- `POST /api/ipv6/disable-token` - 禁用 Token
- `GET /api/ipv6/check` - 检查状态

## 🔧 配置

### 命令行参数

```bash
./ipv6-token-webui --port 8080 --host 127.0.0.1 --log-level debug
```

### 环境变量

```bash
export SERVER_HOST=127.0.0.1
export SERVER_PORT=8080
export LOG_LEVEL=debug
./ipv6-token-webui
```

## 🐛 故障排查

### 端口被占用

```bash
# 查看端口占用
sudo netstat -tlnp | grep 5000

# 使用其他端口
./ipv6-token-webui --port 5001
```

### 权限不足

```bash
# 使用 root 运行
sudo ./ipv6-token-webui
```

### NetworkManager 未运行

```bash
# 启动 NetworkManager
sudo systemctl start NetworkManager
```
