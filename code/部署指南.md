# IPv6 Token WebUI - 部署指南

## 📦 编译产物

编译后的二进制文件位于：
- **开发版本**: `target/debug/ipv6-token-webui`
- **生产版本**: `target/release/ipv6-token-webui`

生产版本已经过优化，体积约 4MB，包含所有前端资源。

## 🚀 快速部署

### 方式一：直接运行二进制文件

1. 将编译好的二进制文件复制到目标服务器
2. 运行程序：

```bash
./ipv6-token-webui
```

3. 访问 http://localhost:5000

### 方式二：使用 Docker

```bash
# 构建镜像
docker build -t ipv6-token-webui .

# 运行容器
docker run -d \
  --name ipv6-token-webui \
  --network host \
  --cap-add=NET_ADMIN \
  ipv6-token-webui
```

### 方式三：使用 Docker Compose

```bash
docker compose up -d
```

## ⚙️ 配置

### 命令行参数

```bash
ipv6-token-webui [选项]

选项:
  -p, --port <PORT>            服务器监听端口 [默认: 5000]
  -H, --host <HOST>            服务器监听地址 [默认: 0.0.0.0]
  -l, --log-level <LOG_LEVEL>  日志级别 [默认: info]
  -h, --help                   显示帮助信息
  -V, --version                显示版本信息
```

### 环境变量

```bash
export SERVER_HOST=0.0.0.0
export SERVER_PORT=5000
export LOG_LEVEL=info
```

## 🔒 安全注意事项

1. **输入验证**: 所有输入都经过严格验证
   - Token 格式: 只允许十六进制字符和冒号
   - 接口名称: 只允许字母、数字、下划线、连字符

2. **权限要求**: 
   - 需要 root 权限执行网络配置命令
   - 建议使用 systemd 服务运行

3. **网络安全**:
   - 建议配置防火墙限制访问
   - 生产环境建议使用 Nginx 反向代理

## 📋 系统服务配置

创建 systemd 服务文件 `/etc/systemd/system/ipv6-token-webui.service`:

```ini
[Unit]
Description=IPv6 Token WebUI
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/ipv6-token-webui
ExecStart=/opt/ipv6-token-webui/ipv6-token-webui
Restart=on-failure
RestartSec=5s

Environment="LOG_LEVEL=info"

[Install]
WantedBy=multi-user.target
```

启用并启动服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable ipv6-token-webui
sudo systemctl start ipv6-token-webui
sudo systemctl status ipv6-token-webui
```

## 🧪 测试

### 测试 API 端点

```bash
# 获取系统信息
curl http://localhost:5000/api/system/info

# 检查 Token 状态
curl http://localhost:5000/api/ipv6/check

# 启用 Token
curl -X POST http://localhost:5000/api/ipv6/enable-token \
  -H "Content-Type: application/json" \
  -d '{

    "interface": "eth0",
    "token": "::888",
    "privacy_mode": 2

  -d '{
    "connection_name": "Wired connection 1",
    "interface": "eth0"
  }'
```

## 📝 故障排查

### 问题：无法访问 Web 界面

1. 检查服务是否运行：`ps aux | grep ipv6-token-webui`
2. 检查端口是否被占用：`netstat -tlnp | grep 5000`
3. 检查防火墙规则：`sudo ufw status`

### 问题：权限不足

1. 确保使用 root 权限运行
2. 检查 NetworkManager 是否正常运行
3. 查看日志获取详细错误信息

### 问题：编译失败

1. 确保 Rust 版本 >= 1.70：`rustc --version`
2. 更新依赖：`cargo update`
3. 清理并重新编译：`cargo clean && cargo build --release`

## 🐳 Docker 部署详细说明

### Dockerfile 说明

项目使用多阶段构建：
1. 第一阶段：编译 Rust 程序
2. 第二阶段：创建最小运行镜像

### Docker Compose 配置

```yaml
version: '3.8'

services:
  ipv6-token-webui:
    build: .
    container_name: ipv6-token-webui
    network_mode: host
    cap_add:
      - NET_ADMIN
    restart: unless-stopped
    environment:
      - LOG_LEVEL=info
```

### 网络模式说明

- **host 模式**（推荐）: 容器直接使用主机网络，可以访问 NetworkManager
- **bridge 模式**: 需要端口映射，但无法直接配置主机网络
