# 认证配置指南

## 📖 概述

IPv6 Token WebUI 内置了完整的认证系统，保护您的 Web 界面免受未授权访问。本指南将帮助您了解和配置认证系统。

## 🔐 认证流程

### 首次启动

1. **启动程序**
   ```bash
   ./ipv6-token-webui
   ```

2. **访问 Web 界面**
   - 浏览器打开 `http://localhost:5000`
   - 系统检测到未设置密码，显示"首次设置"页面

3. **设置初始密码**
   - 输入密码（至少 6 位）
   - 确认密码
   - 点击"设置密码"按钮
   - 系统自动登录并进入主界面

### 后续访问

1. **访问 Web 界面**
   - 浏览器打开 `http://localhost:5000`
   - 系统显示登录页面

2. **输入密码登录**
   - 输入之前设置的密码
   - 点击"登录"按钮
   - 登录成功后进入主界面

3. **会话管理**
   - 登录后会话默认保持 30 分钟
   - 每次操作会自动延长会话时间
   - 会话过期后需要重新登录

## 🛠️ 配置文件

### 配置文件位置

- **直接运行**: `./config/config.yaml`（程序同目录）
- **Docker 运行**: `./config/config.yaml`（通过卷挂载持久化）

### 配置文件结构

```yaml
auth:
  # 密码哈希（Argon2id 算法）
  password_hash: "$argon2id$v=19$m=19456,t=2,p=1$..."
  
  # 会话超时时间（分钟）
  session_timeout_minutes: 30
  
  # 最大登录失败次数
  max_login_attempts: 5
  
  # IP 锁定时长（分钟）
  lockout_duration_minutes: 15
```

### 配置项说明

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `password_hash` | `None` | 密码哈希值，首次启动为空 |
| `session_timeout_minutes` | `30` | 会话超时时间（分钟） |
| `max_login_attempts` | `5` | 最大登录失败次数 |
| `lockout_duration_minutes` | `15` | IP 锁定时长（分钟） |

### 修改配置

1. **停止程序**
   ```bash
   # 如果使用 systemd
   sudo systemctl stop ipv6-token-webui
   
   # 如果使用 Docker
   docker compose down
   ```

2. **编辑配置文件**
   ```bash
   nano config/config.yaml
   ```

3. **修改配置项**
   ```yaml
   auth:
     password_hash: "$argon2id$v=19$m=19456,t=2,p=1$..."
     session_timeout_minutes: 60  # 改为 60 分钟
     max_login_attempts: 3        # 改为 3 次
     lockout_duration_minutes: 30 # 改为 30 分钟
   ```

4. **重启程序**
   ```bash
   # 如果使用 systemd
   sudo systemctl start ipv6-token-webui
   
   # 如果使用 Docker
   docker compose up -d
   ```

## 🔑 密码管理

### 修改密码（CLI 方式）

1. **使用 CLI 命令**
   ```bash
   ./ipv6-token-webui --set-password
   ```

2. **按提示输入**
   ```
   请输入新密码: ********
   请确认新密码: ********
   密码已成功更新！
   ```

3. **Docker 环境**
   ```bash
   # 进入容器
   docker exec -it ipv6-token-webui bash
   
   # 修改密码
   ipv6-token-webui --set-password
   
   # 退出容器
   exit
   ```

### 重置密码（忘记密码）

如果忘记密码，可以通过删除配置文件重置：

1. **停止程序**
   ```bash
   sudo systemctl stop ipv6-token-webui
   # 或
   docker compose down
   ```

2. **删除配置文件**
   ```bash
   rm config/config.yaml
   ```

3. **重启程序**
   ```bash
   sudo systemctl start ipv6-token-webui
   # 或
   docker compose up -d
   ```

4. **重新设置密码**
   - 访问 Web 界面
   - 系统会再次显示"首次设置"页面
   - 设置新密码

## 🔒 安全特性

### 密码哈希

- **算法**: Argon2id（2015 年密码哈希竞赛冠军）
- **参数**: 
  - 内存成本: 19456 KB
  - 时间成本: 2 次迭代
  - 并行度: 1
- **盐值**: 随机生成，每个密码唯一

### 会话管理

- **会话 ID**: UUID v4（128 位随机数）
- **存储方式**: 内存存储（重启服务器会清除所有会话）
- **超时机制**: 
  - 默认 30 分钟无操作自动过期
  - 每次操作自动延长会话时间
- **后台清理**: 每 5 分钟自动清理过期会话

### 登录保护

- **失败追踪**: 按 IP 地址追踪登录失败次数
- **自动锁定**: 
  - 默认 5 次失败后锁定 IP
  - 锁定时长默认 15 分钟
  - 锁定期间该 IP 无法登录
- **自动解锁**: 锁定时间到期后自动解锁

### IP 地址提取

- **直接访问**: 使用客户端真实 IP
- **代理访问**: 支持以下 HTTP 头：
  - `X-Forwarded-For`
  - `X-Real-IP`
  - `Forwarded`

## 🐳 Docker 配置

### 配置持久化

所有 Docker Compose 文件已配置卷挂载：

```yaml
volumes:
  - ./config:/app/config
```

这确保：
- ✅ 配置文件持久化
- ✅ 重启容器不丢失密码
- ✅ 可以在宿主机直接编辑配置

## 🚨 常见问题

### Q1: 忘记密码怎么办？

**A**: 删除配置文件 `config/config.yaml`，重启程序，重新设置密码。

### Q2: 会话过期太快怎么办？

**A**: 编辑 `config/config.yaml`，增加 `session_timeout_minutes` 的值。

### Q3: 登录失败次数太多被锁定怎么办？

**A**: 等待锁定时间到期（默认 15 分钟），或者重启程序清除锁定记录。

### Q4: Docker 重启后需要重新设置密码吗？

**A**: 不需要。配置文件通过卷挂载持久化，重启容器不会丢失密码。

### Q5: 可以禁用认证吗？

**A**: 不可以。认证系统是强制启用的，以保护您的系统安全。

### Q6: 多个用户可以同时登录吗？

**A**: 可以。每个用户登录后会获得独立的会话 ID。

### Q7: 会话存储在哪里？

**A**: 会话存储在内存中，重启程序会清除所有会话（用户需要重新登录）。

### Q8: 如何查看当前配置？

**A**: 查看 `config/config.yaml` 文件。

```bash
cat config/config.yaml
```

## 📊 安全建议

### 密码强度

- ✅ **推荐**: 至少 12 位，包含大小写字母、数字、特殊字符
- ⚠️ **最低要求**: 6 位
- ❌ **避免**: 纯数字、常见单词、个人信息

### 会话超时

- ✅ **推荐**: 30-60 分钟
- ⚠️ **高安全环境**: 10-15 分钟
- ❌ **不推荐**: 超过 120 分钟

### 网络访问

- ✅ **最安全**: 仅本地访问（`127.0.0.1`）
- ⚠️ **局域网访问**: 使用防火墙限制 IP 范围
- ❌ **公网访问**: 必须配合反向代理（Nginx + HTTPS）

### 配置文件权限

```bash
# 设置配置文件权限（仅所有者可读写）
chmod 600 config/config.yaml

# 设置配置目录权限
chmod 700 config/
```
