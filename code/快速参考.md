# 快速参考

## 🔒 监听地址配置

### 默认配置

| 运行方式 | 默认监听地址 | 访问方式 | 安全性 |
|---------|------------|---------|--------|
| 二进制运行 | `127.0.0.1:5000` | 仅本地 | 🟢 高 |
| Docker 容器 | `0.0.0.0:5000` | 本地+远程 | 🟡 中 |

### 修改监听地址

```bash
# 二进制运行
sudo ./ipv6-token-webui -H 127.0.0.1  # 仅本地（默认）
sudo ./ipv6-token-webui -H 0.0.0.0    # 所有接口

# Docker
# 编辑 docker-compose.local.yml，取消注释：
# command: ["-H", "127.0.0.1"]  # 仅本地
# command: ["-H", "0.0.0.0"]    # 所有接口
```

### 安全建议

✅ **推荐配置**:
- 本地开发: `127.0.0.1`
- 内网 NAS: `0.0.0.0` + 防火墙
- 公网服务器: `127.0.0.1` + Nginx 反向代理

❌ **不推荐**:
- 公网直接暴露 `0.0.0.0` 且无防火墙

## 🚀 快速启动

### 二进制运行

```bash
cd code
cargo build --release
sudo ./target/release/ipv6-token-webui

# 访问: http://localhost:5000
```

### Docker 运行

```bash
cd code

# 方式 1: 远程镜像（推荐，最快）
docker compose -f docker-compose.remote.yml up -d

# 方式 2: 本地构建
docker compose -f docker-compose.local.yml up -d

# 访问: http://localhost:5000
```

## 📝 常用命令

### 二进制

```bash
# 启动（默认配置）
sudo ./ipv6-token-webui

# 自定义端口和地址
sudo ./ipv6-token-webui -H 0.0.0.0 -p 8080

# 查看帮助
./ipv6-token-webui --help

# 跳过 root 检查（测试用）
./ipv6-token-webui --skip-root-check
```

### Docker

```bash
# 启动
docker compose up -d

# 查看日志
docker compose logs -f

# 停止
docker compose down

# 重启
docker compose restart

# 更新镜像
docker compose pull
docker compose up -d
```

## 🔍 故障排查

### 无法访问 WebUI

```bash
# 1. 检查服务是否运行
docker ps
# 或
ps aux | grep ipv6-token-webui

# 2. 检查监听地址
sudo netstat -tlnp | grep 5000

# 3. 检查防火墙
sudo ufw status

# 4. 查看日志
docker compose logs
# 或
journalctl -u ipv6-token-webui
```

### 权限错误

```bash
# 确保使用 root 运行
sudo ./ipv6-token-webui

# 或跳过检查（仅测试）
./ipv6-token-webui --skip-root-check
```

### 端口被占用

```bash
# 查看占用端口的进程
sudo netstat -tlnp | grep 5000

# 使用其他端口
sudo ./ipv6-token-webui -p 8080
```
