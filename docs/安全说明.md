# 安全说明

本文档说明 IPv6 Token WebUI 的安全特性和最佳实践。

---

## 🔒 安全特性

### 输入验证
- **严格的格式验证**: 使用正则表达式验证所有用户输入
- **长度限制**: Token (64字符)、接口名 (32字符)、连接名 (128字符)
- **特殊字符过滤**: 禁止 shell 特殊字符（`;`, `|`, `&`, `$`, `(`, `)`, `<`, `>`, `` ` ``, `"`, `'`, `\n`, `\r`, `\`, `*`, `?`, `[`, `]`, `{`, `}`, `!`）

### 命令执行安全
- **脚本白名单**: 仅允许执行预定义的脚本
- **路径规范化**: 防止路径遍历攻击（`../`）
- **参数数组传递**: 防止命令注入
- **超时控制**: 60 秒超时，防止资源耗尽
- **并发限制**: 最多 5 个并发命令

### 网络安全
- **速率限制**: 每秒 2 个请求，突发 10 个
- **默认本地监听**: `127.0.0.1`（仅本地访问）
- **CORS 配置**: 可配置跨域访问
- **CORS 说明**: 为方便局域网使用，可能会放开跨域访问；如果暴露到公网，建议关闭跨域或仅允许可信域名
- **日志信息说明**: Token 操作会返回包含 IPv6 地址的日志用于排障；请避免公网暴露服务或对外分享日志内容

### 权限管理
- **Root 权限检查**: 启动时验证 root 权限
- **平台检查**: 仅支持 Linux 系统
- **测试模式**: `--skip-root-check` 用于开发测试

### 错误处理
- **日志分离**: 详细错误记录到日志，通用消息返回给客户端
- **不泄露信息**: 避免在响应中包含系统路径、命令等敏感信息

## 🚀 安全部署

### 1. 基本部署（仅本地访问）

```bash
# 编译
cargo build --release

# 运行（需要 root）
sudo ./target/release/ipv6-token-webui

# 访问
http://localhost:5000
```

### 2. 远程访问（推荐）

**强烈建议使用反向代理 + HTTPS**:

```nginx
# Nginx 配置
server {
    listen 443 ssl http2;
    server_name your-domain.com;
    
    # SSL 证书
    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;
    
    # SSL 安全配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    
    # 安全头
    add_header Strict-Transport-Security "max-age=31536000" always;
    add_header X-Frame-Options "DENY" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    
    # 反向代理
    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# HTTP 重定向到 HTTPS
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}
```

### 3. 防火墙配置

```bash
# UFW（推荐）
sudo ufw allow from 192.168.1.0/24 to any port 5000
sudo ufw enable

# 或 iptables
sudo iptables -A INPUT -p tcp --dport 5000 -s 192.168.1.0/24 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 5000 -j DROP
sudo iptables-save > /etc/iptables/rules.v4
```

### 4. 环境变量配置

```bash
# 仅本地访问
export SERVER_HOST="127.0.0.1"
export SERVER_PORT="5000"
export LOG_LEVEL="info"

# 远程访问（配合反向代理）
export SERVER_HOST="127.0.0.1"  # 仍然监听本地
export SERVER_PORT="5000"
export LOG_LEVEL="warn"  # 生产环境减少日志
```

## ⚠️ 安全注意事项

### 必须遵守
1. ✅ **必须以 root 运行**: 修改 NetworkManager 配置需要 root 权限
2. ✅ **默认仅本地访问**: 不要直接暴露到公网
3. ✅ **使用 HTTPS**: 远程访问必须使用 HTTPS
4. ✅ **配置防火墙**: 限制访问来源 IP
5. ✅ **定期更新**: 及时更新依赖和系统

### 强烈建议
6. ✅ **添加身份验证**: HTTP Basic Auth 或更强的机制
7. ✅ **监控日志**: 定期检查异常访问
8. ✅ **备份配置**: 修改前备份 NetworkManager 配置
9. ✅ **测试环境**: 先在测试环境验证
10. ✅ **最小权限**: 仅授予必要的访问权限

### 不要做
❌ **不要直接监听 0.0.0.0**: 除非配合防火墙和身份验证  
❌ **不要使用 HTTP**: 远程访问必须使用 HTTPS  
❌ **不要禁用验证**: 不要修改输入验证逻辑  
❌ **不要暴露日志**: 日志可能包含敏感信息  
❌ **不要忽略警告**: 注意日志中的安全警告

## 🆘 安全事件响应

### 发现安全问题

1. **立即停止服务**:
   ```bash
   sudo systemctl stop ipv6-token-webui
   ```

2. **检查日志**:
   ```bash
   sudo journalctl -u ipv6-token-webui -n 1000 > security-incident.log
   ```

3. **分析攻击**:
   - 检查异常 IP 地址
   - 检查异常请求模式
   - 检查系统完整性

4. **修复和恢复**:
   - 更新到最新版本
   - 修改密码/密钥
   - 加强防火墙规则
   - 恢复服务

5. **报告问题**:
